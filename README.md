# Premium Architecture Portfolio

A premium 3D architecture portfolio website built with Next.js, React Three Fiber, Framer Motion, and Tailwind CSS.

## Features

- **3D Interactive Building** - Rotating 3D model on homepage with React Three Fiber
- **Glassmorphism UI** - Modern frosted glass effects
- **Smooth Animations** - Framer Motion and GSAP for smooth transitions
- **Responsive Design** - Fully responsive across all devices
- **SEO Optimized** - Built-in SEO with Open Graph tags
- **Professional Resume** - Downloadable resume and detailed experience section

## Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **React Three Fiber** - Declarative Three.js for 3D graphics
- **Framer Motion** - Production-ready animations
- **GSAP** - Advanced animations and scroll control
- **Zod** - Schema validation

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Project Structure

```
src/
├── app/              # Next.js App Router

│   └── projects/   # Project pages

│   ├── layout/     # Layout components
│   └── ui/         # UI sections
├── data/           # Static data
├── lib/            # Utilities

```
